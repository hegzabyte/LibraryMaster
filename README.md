# :books: LibraryMaster - Modern Kütüphane Otomasyon Sistemi

LibraryMaster; C# WinForms tabanlı, Microsoft Access (.mdb) veritabanı altyapısını kullanan profesyonel bir kütüphane yönetim çözümüdür.

![Ana Menü](https://raw.githubusercontent.com/hegzabyte/LibraryMaster/main/AnaMenu.png)

## :sparkles: Öne Çıkan Özellikler

*   :book: **Kitap Yönetimi:** Kitap ekleme, listeleme ve detaylı arama işlemleri.
*   :busts_in_silhouette: **Üye Takibi:** Kütüphane üyelerinin ve öğrenci listelerinin yönetimi.
*   :arrows_counterclockwise: **Emanet Sistemi:** Kitap ödünç verme ve geri alma süreçlerinin takibi.
*   :warning: **Gecikme Kontrolü:** Teslim tarihi geçen kitapların anlık takibi.
*   :floppy_disk: **Hafif Veritabanı:** Kurulum gerektirmeyen MS Access (.mdb) altyapısı.

## 🛠️ Kullanılan Teknolojiler

*   **Dil:** C# (.NET Framework)
*   **Veritabanı:** Microsoft Access (OleDb)
*   **Arayüz:** WinForms
